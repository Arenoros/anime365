# Экраны приложения

Описание всех экранов для дизайн-проекта **Kadr**. Термины — из
[GLOSSARY.md](../GLOSSARY.md), решения — из [docs/adr](adr/). Для каждого
экрана указано, какие данные реально отдаёт API: рисовать стоит только то,
что можно заполнить.

---

## Общее

### Навигация

Четыре таба внизу: **Главная**, **Каталог**, **Список** (Библиотека),
**Профиль**. Бокового меню нет.

Поверх табов, отдельными экранами: Аниме, Выбор Перевода (нижний лист),
Плеер, Вход, Нужна Подписка, Публикация, Мои публикации, Настройки.
Плеер скрывает табы и системные панели. «Назад» сворачивает его в окно поверх
приложения: видео играет, пока ходишь по табам.

С любого экрана до Плеера — не больше двух касаний.

### Состояния, которые есть у каждого экрана с данными

| Состояние | Что показываем |
|---|---|
| Загрузка | Скелетоны той же геометрии, что и контент. Никаких спиннеров на весь экран. |
| Пусто | Пояснение и действие («Сбросить фильтры», «Найти аниме»). |
| Ошибка сети | Текст по-человечески и кнопка «ПОВТОРИТЬ». Тостов «Ошибка» нет. |
| Офлайн | Данные из кэша плюс тонкая плашка «Нет сети — показаны сохранённые данные». |
| Нужен вход | Только там, где без входа нельзя: Плеер, Публикация. |
| Нужна Подписка | Только Плеер и Скачивание. |

### Тема

Светлая и тёмная из Kadr, по умолчанию — как в системе. Плеер всегда
чёрный.

### Уведомления о новых сериях

Раз в 6 часов приложение проверяет аниме со Статусом «Смотрю». Новый Эпизод —
уведомление «Вышла 8 серия · Провожающая в последний путь Фрирен», касание
открывает Плеер. Отдельного экрана уведомлений нет: новые Эпизоды видны
счётчиком на табе «Список» и бейджами в нём.

### Аниме 18+

«Контент 18+» по умолчанию выключен. После включения в Каталоге доступен
переключатель «Аниме / Хентай»; запрос и фильтры при переключении сохраняются.
После перезапуска выбран раздел «Аниме». Главная и общая лента показывают
обычное аниме, личные записи могут содержать hentai при включённой настройке.

Выключение скрывает контент 18+ везде, включая Список, историю, Скачанное и
уведомления, и закрывает его карточки и Плеер. Записи, Прогресс и файлы
сохраняются. Начатые Скачивания продолжаются в фоне, скрытые в интерфейсе;
общее служебное уведомление Android остаётся без названий и постеров.

### Свойства данных, которые влияют на вёрстку

- Русские названия длинные: «Провожающая в последний путь Фрирен». Заголовок
  экрана Аниме — до трёх строк, карточка — две строки с многоточием.
- Второе название — латиницей («Sousou no Frieren»), мельче и приглушённее.
- Рейтинг — только MyAnimeList (9.24 → «9.2»). Числа оценок нет.
  У части аниме рейтинга нет вовсе.
- У одного Эпизода бывает **до сотни Переводов**.
- Команда Перевода бывает пустой.
- Даты выхода будущих Эпизодов в API нет.
- Студии в API нет.

## 1. Главная

**Зачем**: вернуться к просмотру и увидеть, что вышло нового.

**Блоки сверху вниз**:

1. **Поле поиска** — касание открывает Каталог с фокусом в поле.
2. **Продолжить просмотр** — горизонтальный ряд карточек: постер, «7 серия»,
   полоска позиции внутри Эпизода. Касание — сразу Плеер с тем же Переводом.
   Блока нет, если продолжать нечего.
3. **Новые серии** — лента, сгруппированная по датам («Сегодня», «Вчера»,
   «21.10.2026»). Одна строка на **Эпизод**, а не на Перевод, иначе одна серия
   займёт десяток строк. Строка: миниатюра постера, «7 серия» и название
   аниме, время. Аниме со Статусом «Смотрю» выделяются. Касание — Плеер с
   запомненным Переводом, если его нет — Выбор Перевода.
4. **Онгоинги** — горизонтальный ряд постеров (сейчас их 195) и «ВСЕ» —
   Каталог с фильтром «Онгоинг».
5. **Рейтинг сезона** — первые 10 аниме текущего сезона по рейтингу
   MyAnimeList: место, миниатюра, название, рейтинг.

**Действия**: потянуть вниз — обновить.

**Kadr**: SearchField, SectionHeader, PosterCard, EpisodeFeed, RankingListItem.

## 2. Каталог

**Зачем**: найти аниме по названию или подобрать по фильтру.

**Содержимое**:

- **Поле поиска** — поиск по названию, по мере ввода.
- **Чипы фильтров**: Тип (ТВ, Фильм, OVA, ONA, Спешл, Клип), Год, Сезон,
  Жанры (несколько сразу, режим «все выбранные» или «любой из»), «Только
  онгоинги». Выбранные чипы видны всегда, «Сбросить» — одним касанием.
- **Сетка постеров**: 3 колонки на телефоне, 5 от 600dp, 6 от 840dp.
  Бесконечная прокрутка.

**Данные**: списка жанров в API нет — он поставляется вместе с приложением.

**Состояния**: «Ничего не найдено» с кнопкой «СБРОСИТЬ ФИЛЬТРЫ».

**Kadr**: SearchField, Chip, PosterCard.

## 3. Список (Библиотека)

**Зачем**: личный список аниме и Скачанное.

**Содержимое**:

- **Вкладки**: Смотрю · Запланировано · Просмотрено · Брошено · Скачанное.
- **Строка аниме**: постер, название, «12 из 28 эп.», бейдж количества новых
  Эпизодов (только во вкладке «Смотрю»). Касание — экран Аниме, кнопка
  справа — продолжить просмотр сразу.
- **Счётчик Новых Эпизодов** на табе «Список» в нижней навигации.
- **Начатое аниме** попадает во «Смотрю» само, если Статус ему ещё ни разу не
  выбирали. Убранное из Списка обратно само не возвращается: его Прогресс и
  запомненный Перевод остаются и уходят в Экспорт.

**Первое открытие**: один раз — пояснение «Список хранится только на этом
устройстве. Сохранить копию можно в Профиле → Экспорт» (ADR 0001).

**Вкладка «Скачанное»** — последняя: группы по аниме, внутри — Эпизоды:
Команда, Разрешение, размер. Состояния строки: в очереди, качается N %, ждёт
сети или Wi-Fi, готово, ошибка. Сверху — сколько места занято. Касание
готового — Плеер, касание ошибки — скачать заново. Удаление свайпом или
выбором нескольких (долгое нажатие), всегда с подтверждением.

**Пусто**: «Добавьте аниме кнопкой В СПИСОК на его странице».

**Kadr**: Tabs, PosterCard (или строка списка), Badge.

## 4. Профиль

**Гость**: кнопка «ВОЙТИ» и одна строка зачем: смотреть видео можно только
со входом и подпиской.

**После входа**:

- Имя пользователя.
- **Подписка**: «Активна до 15.03.2027» или «Нет подписки» и
  «ОФОРМИТЬ НА САЙТЕ» (открывает браузер, оплаты в приложении нет).

**Пункты** (одинаково для гостя и пользователя, кроме «Выйти»):
Мои публикации · Настройки · Экспорт Списка · Импорт Списка ·
Проверить обновления · О приложении · Выйти.

«Проверить обновления» — только в релизной сборке: новая версия на GitHub —
диалог «Доступно обновление», нет — «Установлена последняя версия».

**Kadr**: TopAppBar, кнопки, строки меню.

## 5. Аниме

**Как попасть**: из любой карточки или строки.

**Шапка**: постер; название (до трёх строк) и второе название; «ТВ сериал ·
28 эп. · Осень 2023»; бейдж «Онгоинг», «Вышел» или «Анонс» (ни одного
вышедшего Эпизода); рейтинг; чипы жанров
(касание — Каталог с этим жанром).

**Главные кнопки**: «НАЧАТЬ ПРОСМОТР» или «ПРОДОЛЖИТЬ · 7 серия»;
«В СПИСОК» — лист выбора Статуса (Смотрю, Запланировано, Просмотрено,
Брошено, Убрать из списка). Если аниме уже в Списке — кнопка показывает
Статус.

**Вкладки**:

- **Описание** — текст. Описаний бывает несколько из разных источников
  (Шикимори, World Art) — переключатель источника. Ниже — внешние ссылки
  (MyAnimeList, Шикимори, AniList, Википедия и др.).
- **Серии** — сетка Эпизодов. Трейлеры, спешлы и фильмы — широкими кнопками
  отдельно от нумерованных. Состояния кнопки: просмотрен, текущий (есть
  позиция), новый, ещё не вышел (без даты — её в API нет). Для 100+ Эпизодов —
  диапазоны «1–50», «51–100». Долгое нажатие — «Скачать», «Скачать эту и
  следующие» (если после неё есть серии того же типа), «Отметить
  просмотренным». «Скачать» открывает Выбор Перевода: касание строки ставит
  серию в очередь. «Эту и следующие» — следующие серии той же Командой;
  серии без неё и уже скачанные пропускаются.

**Меню в шапке**: Опубликовать перевод · Открыть на сайте · Поделиться.

**Kadr**: TitleHeader, Rating, Chip, Tabs, EpisodeGrid.

## 6. Выбор Перевода

Нижний лист. **Как попасть**: касание Эпизода на экране Аниме, кнопка
«Перевод» в Плеере.

**Шаг 1 — Вид перевода**: горизонтальные чипы только из тех видов, что есть у
этого Эпизода: Русская озвучка, Русские субтитры, Украинская озвучка,
Английская озвучка, Английские субтитры, Японские субтитры, Другая озвучка,
RAW. По умолчанию — последний выбранный для этого аниме, иначе из настроек.

**Шаг 2 — список Переводов** выбранного вида, в порядке сайта. Строка:
Команда (или «Авторы не указаны»), бейдж Источника (TV / BD / DVD),
Разрешение (720p / 1080p / 2160p). Одна Команда может дать два Перевода —
TV и BD — это две строки. Перевод, которым смотрели прошлый Эпизод, отмечен.
Вшитые субтитры или Отдельные — в списке не помечается: это становится
известно только при запуске. Скачанный Перевод отмечен «Скачано — смотреть
можно без сети».

**Без входа / без подписки**: список виден полностью. Сверху плашка «Для
просмотра нужна подписка», касание строки ведёт на Вход или на Нужна
Подписка.

**Kadr**: TranslationSelector.

## 7. Плеер

**Портрет**: видео 16:9 сверху; под ним — название, «7 серия · Команда»,
кнопка «Перевод», следующий Эпизод и сетка Эпизодов.
**Ландшафт**: во весь экран, без системных панелей.

**Управление** (скрывается через 3 с):

- Верх: назад, «7 серия · Команда», «Перевод», «Настройки».
- Центр: предыдущая серия, −10 с, пауза/воспроизведение, +10 с, следующая
  серия. Двойное касание по краям — перемотка.
- Низ: прогресс с буфером, время, бейдж Разрешения, полноэкранный режим,
  «+85 с» в первые 5 минут Эпизода — пропуск опенинга (меток опенинга в API
  нет).
- Настройки: Разрешение (1080p, 720p, 360p; 2160p — если есть у Перевода),
  скорость 0.5–2×, «Субтитры» вкл/выкл — только для Отдельных субтитров.
  Смена Разрешения не сбрасывает позицию.

**Конец Эпизода**: карточка «Следующая серия через 5 с» с «ОТМЕНА». Тот же
Перевод следующего Эпизода; если такой Команды нет — снекбар и Выбор
Перевода. Автопереход выключен в Настройках — серия просто останавливается.
Кнопки соседних серий подбирают Перевод так же.

**Просмотрено**: Эпизод досмотрен с 85 % — дальше обычно эндинг и анонс.
Переход к следующей серии, кнопкой или автопереходом, отмечает текущую
просмотренной, где бы её ни остановили. Переход к предыдущей — не отмечает.

**Окно поверх приложения**: «Назад», стрелка вверху или свайп вниз по видео
в портрете сворачивают Плеер в окно 16:9 в углу над табами; видео не
прерывается. Свайп ведёт видео за пальцем: оно уменьшается и едет к углу,
остальное гаснет, под ним видно приложение. Отпустили дальше трети пути или
быстрым взмахом вниз — Плеер доезжает до окна, иначе возвращается. «Назад» и
стрелка сворачивают тем же движением; в ландшафте — сразу. Касание окна — развернуть,
✕ — закрыть, кнопка в углу — пауза. Окно перетаскивается и прилипает к
ближайшему углу. Открыли другую серию — она заменяет свёрнутую. Если
смотреть нечего (ошибка, нужен вход или подписка) — «Назад» закрывает Плеер.

**Фон и PiP**: вышли из приложения, пока видео играет, развёрнутым или в
окне, — «картинка в картинке»; звук продолжает играть в фоне, управление —
из уведомления и с гарнитуры.

**Ошибки**: не выполнен вход — Вход; нет подписки — Нужна Подписка; нет сети —
«ПОВТОРИТЬ». Скачанный Эпизод играет без сети; следующая серия без сети —
если она скачана той же Командой.

**Kadr**: Player, TranslationSelector, EpisodeGrid.

## 8. Вход

Страница входа сайта во встроенном браузере: там же вход через ВКонтакте.
Своей формы логина и пароля в приложении нет (ADR 0005).

**Что рисовать**: только рамку — TopAppBar «Вход» с крестиком, полоса
загрузки, состояние «Не удалось войти — ПОВТОРИТЬ». После входа экран сам
закрывается и возвращает туда, откуда пришли.

## 9. Нужна Подписка

Полноэкранное пояснение, а не ошибка: «Видео доступно с подпиской
anime365», кнопка «ОФОРМИТЬ НА САЙТЕ» (браузер) и «Я уже оформил — ОБНОВИТЬ»
(перепроверяет статус).

## 10. Публикация

**Как попасть**: меню экрана Аниме (аниме уже выбрано), Профиль → Мои
публикации → «+».

**Поля**:

- Аниме (выбрано заранее или поиск).
- Номер эпизода и тип эпизода (ТВ, Фильм, OVA, ONA, Спешл).
- Вид перевода (как в Выборе Перевода).
- Команда — ники через «&», без ссылок; флажок «Я участник Команды».
- Видеофайл — системный выбор файла, показываем имя и размер.
- Субтитры — необязательно, `.ass`.
- Канал загрузки — список от сервера с подписями (например «CDN»),
  рекомендованный выбран.

**Кнопка**: «ОПУБЛИКОВАТЬ» — ставит в очередь и уводит на Мои публикации.
Ошибки проверки сервер возвращает по полям — показываем у каждого поля.

**Kadr**: поля ввода, Chip, Button.

---

## 11. Мои публикации

Локальная очередь (списка своих Переводов в API нет). Строка: аниме,
«3 серия · Русская озвучка», статус:

- В очереди
- Загрузка 43 % — скорость, сколько осталось
- Пауза — нет сети
- Создание Перевода
- **Отправлено** — Перевод создан, но становится виден после проверки на
  сайте (сервер создаёт его неактивным)
- Ошибка — «ПОВТОРИТЬ» или «ИСПРАВИТЬ»

Загрузка многогигабайтных файлов идёт в фоне с уведомлением и продолжается
после обрыва связи.

## 12. Настройки

- **Тема**: как в системе · светлая · тёмная.
- **Перевод по умолчанию**: вид (Русская озвучка, Русские субтитры, …).
- **Автопереход к следующей серии**.
- **Разрешение просмотра**: отдельно по Wi-Fi (1080p) и по мобильной сети
  (720p). Нет у Перевода — ближайшее меньшее.
- **Скачивание**: только по Wi-Fi; Разрешение 720p или ближайшее меньшее.
  Субтитры качаются вместе с видео. Прогресс — в уведомлении.
- **Уведомления о новых сериях** — включено. Выключены — Новые Эпизоды всё
  равно видны в Списке.
- **Контент 18+** — выключено, включает раздел «Хентай» и личные записи 18+.
- **Кэш**: сколько занято, «ОЧИСТИТЬ» (Список и Скачанное не трогает).
- **Отправлять отчёты о сбоях** — выключено. Отчёт без имени и без данных
  входа. Действует сразу, без перезапуска. В сборках без Sentry (dev, форки)
  пункта нет.

---

## 13. Диалоги

- **Доступно обновление** — версия, что нового, «ОБНОВИТЬ» / «ПОЗЖЕ».
  Приложение проверяет само при запуске, не чаще раза в сутки. «ОБНОВИТЬ»
  открывает в браузере APK под архитектуру телефона; «ПОЗЖЕ» — диалог вернётся
  через сутки.
- **Удалить скачанное?** — размер, подтверждение.
- **Импорт Списка** — «Заменить текущий» или «Объединить».
