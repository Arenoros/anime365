# Поведение API, которого нет в спецификации

Проверено живыми запросами 23.10.2026. Спецификация —
[anime365-openapi.yaml](anime365-openapi.yaml). Термины — из
[GLOSSARY.md](../GLOSSARY.md).

## Общее

- Базовый адрес из спецификации — `https://smotret-anime.app/api`;
  `https://smotret-anime.co/api` отвечает тем же.
- Без `fields` каждый элемент `/translations` содержит полные вложенные
  объекты `series` (с внешними ссылками и описаниями) и `episode`. `fields`
  вырезает и их.
- Метода со списком жанров нет: `/api/genres` → 404. У аниме жанры приходят
  как `[{id, title, url}]`.
- `/api/videos/{id}` клиенту не нужен.
- В `links` аниме бывают дубли (две ссылки «википедия (ja)»).
- `worldArtScore: -1` означает «оценки нет». У `myAnimeListScore` два знака
  после точки (`9.24`).
- Онгоингов с `isActive=1` на дату проверки — 195.
- Ошибки приходят с HTTP **200**: `{"error":{"code":404,"message":"Series not found."}}`.
- Даты — московское время без зоны: `2026-10-23 14:50:51`.

## Аниме — `/series`

- Сортировка по умолчанию — по `myAnimeListScore` от большего к меньшему.
  Она же у `query`, `chips` и фильтров по полям, так что «Рейтинг сезона» —
  это просто `?season=Осень 2026&limit=10`.
- `season` в параметре и в ответе — русская строка «Осень 2026»; у 1405 аниме
  она пустая. Зимний сезон подписан следующим годом: «Зима 2016» бывает с
  `year: 2015`.
- Заглушки вместо значений: `year: 0`, `myAnimeListScore: -1`,
  `numberOfEpisodes: 0` (число неизвестно).
- `isActive`: 1 — есть Эпизоды, 0 — анонс (поля `episodes` в ответе нет
  вовсе), -1 и -2 — скрытые записи.
- У 40 аниме `"titles": []` — пустой массив вместо объекта, и пустые `title`.
  У 4454 нет русского названия.
- Будущих Эпизодов в `episodes` нет. `episodeInt` дробный («11.5 серия»).
- `id` Эпизодов идут не по порядку выхода: у Фрирен трейлер (`306115`, вышел
  25.07.2023) старше 1-й серии (`291395`, 29.09.2023). Новые Эпизоды
  приложение узнаёт по `firstUploadedDateTime` — времени сайта, не часов
  устройства.
  Типы Эпизодов: `tv`, `ona`, `ova`, `movie`, `special`, `tv_special`,
  `preview` (трейлер).
- Типы аниме: `tv`, `movie`, `ova`, `ona`, `special`, `tv_special`, `music`,
  `cm` (реклама), `pv` (проморолик).
- На домене `smotret-anime.app` без входа `isHentai=1` и жанр 12 дают
  пустой список. Проверено повторно 25.10.2026.
- Раздел hentai использует `https://hentai365.org/api/series`: список и поиск
  `query` доступны без входа, записи имеют `isHentai: 1`. Проверено 25.10.2026:
  обычный запрос возвращает записи, заведомо отсутствующий текст — пустой список,
  `isHentai=0` — пустой список. Поэтому взрослый каталог запрашивается на этом
  домене и хранится под отдельными ключами кэша.
- Карточка той же записи доступна через `/api/series/{id}` и на обычном домене:
  `isHentai` нужно проверять также при открытии по ID.

### Поиск и фильтр

- `chips` и `query` **не сочетаются**: при `chips` сервер игнорирует `query`.
- `query` сочетается с полями-фильтрами (`type`, `year`, `season`,
  `isAiring`), но `type` принимает одно значение, а жанров среди них нет.
  Поэтому приложение ищет по `query` и применяет фильтры к результатам на
  устройстве.
- Синтаксис `chips` (из скрипта страницы фильтра сайта): части через `;`,
  `genre@=8,35` — все жанры, `genre=8,35` — любой, `genre!=` — исключить,
  при двух и более жанрах — `genre_op=and|or`; `type=tv,movie`;
  `yearseason=autumn_2026` или `yearseason=2026` (сезон без года
  игнорируется); `isAiring=1`.
- Обход всего каталога (29 632 аниме, 23.10.2026) — 74 жанра; их список
  поставляется с приложением.

## Лента — `/translations?feed=recent`

- Отсортирована по `activeDateTime` от новых к старым. `afterId` игнорируется,
  `offset` работает и на малых смещениях быстрый.
- 200 Переводов — примерно 19 часов и 83 Эпизода. С `fields=…,series` ответ
  весит 536 КБ, без — 55 КБ: аниме Ленты берутся из Онгоингов, а 4 из 44,
  которых там нет, — запросом `/series/{id}`.
- Время выхода Эпизода — `episode.firstUploadedDateTime`; новый Перевод к
  давней серии приходит в Ленту с её старой датой.

## Переводы

- Переводы Эпизода — `/translations?episodeId=…&fields=id,episodeId,type,authorsSummary,qualityType,height,priority`.
  Порядок ответа — не порядок сайта: сортировать по `priority` от большего к меньшему.
- Разрешения в Ленте (1000 Переводов подряд): 720 — 91 %, 1080, 576, 480, 540. Видеопоток отдаёт
  несколько Разрешений одного Перевода, `height` в списке — наибольшее.

- У одного Эпизода — до 97 Переводов (1-я серия Фрирен): `voiceRu` 31,
  `raw` 28, `voiceOther` 13, `subRu` 10, `subEn` 6, `voiceEn` 3, `voiceUk` 3,
  `subJa` 3.
- У `voiceOther` странные производные значения: `typeKind: "voiceOth"`,
  `typeLang: "er"`.
- `priority` — порядок сортировки сайта.
- `authorsList` бывает пустым массивом.

## Видеопоток — `GET /api/translations/embed/{id}`

```json
{
  "data": {
    "embedUrl": "https://smotret-anime.co/translations/embed/5987618",
    "download": [{ "height": 1080, "url": "https://smotret-anime.co/translations/mp4/5987618?download=1&height=1080" }],
    "stream":   [{ "height": 1080, "urls": ["https://bcdn.melon-soda.org/route/?m=…&token=HS256-…&expires=1792836419"] }],
    "subtitlesUrl": "/episodeTranslations/5987619.ass?willcache"
  }
}
```

- В проверенных Переводах — разрешения 1080, 720, 360.
- `stream[].urls` — подписанные ссылки CDN с параметром `expires`, живут
  **ровно 24 часа**. Массив — зеркала одного файла.
- Поток — обычный MP4 (`video/mp4`), не HLS. Перемотка через `Range`
  работает (ответ 206). Файл 1080p на 26 минут — 529 МБ.
- `download[].url` без `access_token` → 403, с `access_token` → 302 на свежую
  подписанную ссылку CDN. Сама ссылка с токеном не истекает.
- `subtitlesUrl` — **относительный путь** двух видов:
  - `/episodeTranslations/{id}.ass?willcache` — `Content-Encoding: gzip`;
  - `/translations/ass/{id}?willcache=1` — `Content-Type: text/html`,
    хотя внутри ASS. MIME-тип надо задавать явно.
- Субтитры отдаются **без Токена**: файл по `subtitlesUrl` открыт всем.
- `/episodeTranslations/{id}.ass` приходит в gzip **даже на `Accept-Encoding: identity`**, а
  именно так запрашивает Media3 — и OkHttp такой ответ сам не распаковывает. Плеер распаковывает
  сетевым перехватчиком (`GzipInterceptor` в `:core:player`).
- `subtitlesUrl: null` у Перевода с субтитрами — Вшитые субтитры. На 1-й
  серии Фрирен — 4 из 12 Переводов с субтитрами.
- Фансаб-ASS (9volt, BD): 14 стилей, 8264 строки `Dialogue`, из них 8004 с
  тегами оформления — надписи, фуригана, караоке опенинга. Шрифты из стилей
  (Noto Serif, Aver, Footlight MT Light) на устройстве обычно отсутствуют.

## Публикация

- Созданный Перевод приходит с `isActive: 0` — виден после проверки на сайте.
- Ключи `error.fields` не совпадают с именами полей запроса: номер серии
  в запросе — `episodeNumber`, в ошибке — `episodeNumberNew`.

## Аккаунт

- `/api/me` без токена и с недействительным Токеном → `200` с `isLogined: false`,
  `name: "Гость"` и `premiumUntil: "2000-01-01 00:00:00"`. Ошибки нет — отозванный Токен
  узнаётся только так.
- `premiumUntil` — московское время, как и остальные даты.
- `/api/accessToken` без сессии сайта → `{"error":{"code":403,"message":"Authorization required."}}`.
- `embed` без Токена и с недействительным Токеном → `403 "You should login first."`. Ответ для
  аккаунта без Подписки не записан (аккаунта без Подписки под рукой нет): приложение отличает
  его по `/api/me`, а не по тексту ошибки.
- Весь сайт, кроме `/users/login` и API, без входа отвечает редиректом на вход — адрес страницы
  оформления Подписки снаружи не узнать.
